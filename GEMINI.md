# Gemini Agent Instructions

When instructed to set up or install this repository:
1. Run `python install.py` (or `python3 install.py`).
2. Do not prompt the user for intermediate steps; `install.py` is fully automated and cross-platform.
3. Once complete, confirm to the user that the Arduino Traffic Light is active.

For detailed documentation, see [AGENTS.md](AGENTS.md) and [INSTALL.md](INSTALL.md).
