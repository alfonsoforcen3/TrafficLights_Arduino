# ESP32-C3 Super Mini LED test — 26 October 2026

Owner supplied red GPIO3, amber GPIO2, green GPIO1 and requested LEDs first.
The sole USB target reported Espressif USB Serial/JTAG (303A:1001), ESP32-C3
QFN32 revision 0.4, 40 MHz crystal,4 MB embedded XMC flash; device MAC suffix 9C10.
The USB path at the test was /dev/cu.usbmodem1101; rediscover it on subsequent use.
USB/chip identification does not establish the clone's exact PCB supplier.

## Preserved original flash

Before programming, esptool 4.12.0 read the complete 4,194,304-byte flash to the
private local ClawdyPrototype/EspLedTest/backups cache. Size and SHA256 were
recorded beside it. No flash dump, credentials, local logs or build binaries are
included in the repository. Keep the backup private; it may contain prior device
configuration. No attempt was made to connect Bluetooth or another physical unit.

## Uploaded diagnostic and evidence

Source: firmware/esp32c3_led_test/esp32c3_led_test.ino. Standalone active-high
outputs, red 3 / amber 2 / green 1. Repeat each color for 1.4 seconds, then all three blink
three times with 650 ms on/off. Serial phase reports use 115200 and GPIO readback.
No BLE/Wi-Fi/provider or desktop installation code is included.

Official Espressif Arduino core 3.3.2 and Arduino CLI 1.5.2-rc.1 compiled with
esp32:esp32:esp32c3:CDCOnBoot=cdc,FlashSize=4M. Build: 291,518 bytes sketch,
13,032 bytes global RAM. Core-supplied esptool 5.1.0 uploaded the standard boot
image, partition table, boot application selector and diagnostic application;
all written regions passed hash verification and the unit reset successfully.

After upload, serial enumeration matched the identified board. Actual firmware
reports for red, amber, green, all-on and all-off matched the configured pins and
expected boolean GPIO outputs. The owner then explicitly confirmed: "it works".
This establishes visible LED acceptance for this unit's diagnostic, in addition
to software output readback. It does not qualify the full ESP32 BLE candidate.
