Which AI tools will it work with?

The prototype supports local Codex, Claude Code, Gemini CLI and Cursor hooks. Availability depends on each tool’s installed version and hook support. Ordinary browser chats are not tracked.

What if I’m running more than one chat?

The Mac combines tracked sessions: green waits until all work has finished. Attention takes priority over errors, errors over working, and working over done.

Can I check charging here?

You can follow measured voltage over time on the Mac dashboard. The current clone’s battery sensing and charger specifications still require hardware verification. Do not treat a percentage or voltage trend as approval to charge.
